# Vector Database

A C++ vector search engine being developed as part of the project.

## Current Phase

Phase 0:
- VectorRecord / Metadata data structures
- SIFT .fvecs / .ivecs dataset loader
- Brute-force kNN search
- Squared L2 distance
- Recall@k validation

## Build

cmake -S . -B build
cmake --build build

## Status

Phase 0 implementation in progress.
